# CodixGPT Frontend

Static HTML/CSS/JS web app for CodixGPT.

## Connect to Render

Open `js/app.js` and change:

```js
const API = "http://localhost:10000";
```

to your Render backend URL, for example:

```js
const API = "https://your-codixgpt-service.onrender.com";
```

You can deploy this folder to GitHub Pages, Cloudflare Pages, Netlify, or another static host.
